# ميثاق مشروع عمران مول

## الهدف
بناء منصة مؤسسية موحدة لإدارة الموظفين والعمليات التشغيلية في عمران مول، تشمل تطبيق الموظف ولوحات المشرف ومدير الفرع والموارد البشرية والإدارة العليا ومدير النظام.

## النطاق الوظيفي
- ملفات الموظفين والهيكل التنظيمي والفروع والأقسام والمسميات.
- الحضور والانصراف وتصحيح السجلات والورديات.
- الاستراحات والغداء وفجوات التدخين والمغادرات والمؤقتات الحية.
- الإجازات والطلبات وسير الموافقات.
- الإعلانات والرسائل والمهام والتنبيهات.
- الرواتب والسلف والبدلات والخصومات بعد اعتماد السياسات.
- الأصول والعهد والتدريب والتقييم والمخالفات والمكافآت.
- لوحات متابعة وتقارير وتصدير وسجل تدقيق.
- دعم تعدد الفروع مع عزل صارم للبيانات.

## ثوابت غير قابلة للتجاوز
1. العربية هي اللغة الافتراضية مع RTL، والاستعداد للإنجليزية.
2. العملة JOD بدقة ثلاثة منازل عشرية، والتوقيت المرجعي Asia/Amman.
3. الوقت المعتمد للحضور والمعاملات الحساسة هو وقت الخادم.
4. كل صلاحية تُفحص في الخادم، ولا يُعتمد على إخفاء عناصر الواجهة.
5. عزل الفرع يُطبق في طبقة الخدمة وقاعدة البيانات، وليس عبر فلترة الواجهة فقط.
6. لا تُستخدم بيانات موظفين حقيقية في التطوير أو الاختبارات.
7. لا تُفعّل الرسائل أو الإشعارات الجماعية أو أي أثر مالي قبل الاختبار والموافقة.
8. لا تُعتبر الشاشات التجريبية أو البيانات الوهمية وظائف مكتملة.

## المستخدمون والأدوار
- موظف.
- مشرف قسم/وردية.
- مدير فرع.
- الموارد البشرية.
- الإدارة العليا.
- مدير النظام الأعلى.

الأدوار والصلاحيات يجب أن تكون قابلة للتهيئة، مع نطاق واضح: موظف، قسم، فرع، أو الشركة/جميع الفروع. لا تمنح صلاحية عابرة للفروع افتراضياً.

## حدود هذه المرحلة
هذا المستودع يثبت المعمارية والحوكمة وخطة العمل والبنية الأولية. لا يعني أن النظام جاهز للإنتاج. يجب اعتماد السياسات الداخلية، والتحقق القانوني من قواعد الرواتب والإجازات، ومراجعة المخطط والشفرة واختبارها قبل التشغيل.

## معايير النجاح النهائية
- تطبيق Android وiOS وWeb من قاعدة Flutter واحدة.
- API موثق وقابل للاختبار.
- صلاحيات وعزل فروع مثبتان باختبارات سلبية وإيجابية.
- إشعارات Push تصل بعد إغلاق التطبيق على الأجهزة المدعومة.
- سجل تدقيق للعمليات الحساسة.
- نسخ احتياطي واستعادة مجرّبان.
- لا توجد أسرار في Git أو ثغرات حرجة مفتوحة.
- اجتياز اختبارات القبول والتشغيل الميداني قبل الإطلاق.
