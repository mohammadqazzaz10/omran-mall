# تعريف الإنجاز ومعايير قبول العمل

لا تُعتبر أي مهمة مكتملة إلا عند تحقق البنود المناسبة التالية:

- [ ] المتطلب موثق وسيناريوهات القبول واضحة.
- [ ] التحقق من الهوية والصلاحية ونطاق الفرع في الخادم.
- [ ] لا أسرار أو بيانات موظفين حقيقية أو بيانات وهمية مضللة.
- [ ] حالات النجاح والفشل والتحميل وانقطاع الاتصال معالجة.
- [ ] Unit/Integration/E2E أو Widget tests بحسب طبيعة التغيير.
- [ ] لا توجد أخطاء lint/analyze أو build.
- [ ] تحديث OpenAPI وERD والمستندات عند الحاجة.
- [ ] تسجيل العمليات الحساسة في Audit Log.
- [ ] مراجعة الوصول إلى البيانات والملفات والإشعارات.
- [ ] مراجعة أداء الاستعلامات والفهارس للعمليات الجديدة.
- [ ] خطة migration والنسخ الاحتياطي والرجوع موثقة عند تغيير البيانات.
- [ ] موافقة المراجع ونجاح CI قبل الدمج.

## معايير الإصدار
- لا ثغرات حرجة أو عالية غير معالجة.
- نجاح اختبارات عزل الفروع.
- نجاح استعادة نسخة احتياطية.
- نجاح اختبارات أجهزة حقيقية للإشعارات المطلوبة.
- اعتماد UAT من ممثل الإدارة.
- وجود خطة rollback ومراقبة بعد النشر.
